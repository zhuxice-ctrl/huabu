# 画布工作区收敛与关系线预览设计

## 目标

让 Windows 画布成为主要工作区域：移除画布专属的右侧 Documents 面板，为左侧资源栏和底部 AI 输入区提供可持久化折叠，并让右键拖动关系线具有与锚点拖线一致的实时反馈。

## 范围

### 画布右侧面板

- 从 `CanvasWorkspace` 永久移除 `EditorLayout mode="documents-only"`、右侧调整宽度分隔条和 Documents 恢复按钮。
- 普通笔记、记录与非画布页面继续使用原有编辑器和侧栏状态。
- 不删除全局侧栏 store 中仍被其他页面使用的字段；画布工作区不再读取或呈现这些字段。

### 左侧资源栏

- 展开态在资源栏右边缘提供明确的折叠按钮。
- 折叠态保留约 48px 的窄栏和展开按钮，不遮挡画布工具栏。
- 继续使用现有 `leftSidebarVisible`、`leftWidth` 和持久化机制。
- 用户手动折叠状态在重启后恢复；窄窗口自动折叠不覆盖用户保存的偏好。

### 底部 AI 面板

- 保留现有两个对话层级：输入区与完整历史区。
- 新增 `composerCollapsed` 状态。其为 `true` 时只显示紧凑横条，隐藏 `ChatInput` 和完整摘要。
- 紧凑横条显示：AI 图标、最近一条对话的单行摘要、当前 AI 状态和展开按钮。
- 从输入区收起时，同时关闭完整历史区和历史弹窗；再次展开只恢复输入区，不自动打开完整历史。
- Esc 的收起顺序为：历史弹窗 → 完整历史 → 紧凑横条。
- 折叠不清除草稿、附件、引用、当前会话或滚动位置。
- `composerCollapsed` 使用本地持久化，启动时立即读取缓存状态，并与 Tauri Store 同步。

### 右键拖动关系线

- 节点内任意位置按下右键只创建候选会话，不立即显示连线。
- 指针移动距离达到 4px 后激活关系会话并立即显示预览。
- 预览从源节点最近的有效锚点出发，使用与原生锚点拖线一致的实线曲线、端点与主色高亮。
- 指针移动期间持续更新曲线、目标节点高亮和目标锚点高亮。
- 预览层位于画布节点之上、HUD 之下，不拦截鼠标事件。
- 未达到阈值的右键释放仍打开节点菜单；有效拖线释放后进入现有关系编辑器；取消、失焦或捕获丢失时清理全部预览状态。

## 状态与数据流

1. `CanvasWorkspace` 只根据左侧栏偏好计算画布宽度，不再为 Documents 面板保留空间。
2. 左侧折叠继续通过 `useSidebarStore` 写入 localStorage 与 Tauri Store。
3. `CanvasChatHud` 从 `useChatHudStore` 读取 `composerCollapsed`；折叠只改变呈现层，不改变会话与草稿数据。
4. 右键拖动继续使用 `RelationPointerSession`。达到阈值后，几何更新函数选择源/目标锚点并发布一个可渲染快照。
5. 松开指针后，现有目标校验与关系编辑事务负责最终提交；预览本身不写入画布文档或历史记录。

## 兼容与非目标

- 仅修改 Windows 桌面画布工作区，不新增 Android 或移动端布局。
- 不删除普通编辑器的 Documents 能力。
- 不改变关系的数据模型、路由类型、关系编辑器或碰撞规则。
- 不改变 AI 对话内容的持久化格式，也不把 HUD 折叠状态同步到云端。
- 不重构整个工作区为新的布局框架。

## 验收标准

1. 画布工作区不再渲染右侧 Documents 面板、恢复按钮或右侧分隔条。
2. 左侧栏可通过可见按钮折叠和展开；重启后保持用户上次选择。
3. AI 输入区可收起为紧凑横条；横条可恢复输入区；草稿和附件保持不变。
4. 重启后 AI 输入区恢复上次折叠状态。
5. Esc 按既定层级收起，不会一次清除会话或草稿。
6. 节点右键单击仍打开菜单，长时间按住但不移动也不会建立关系。
7. 右键拖动达到 4px 后立即出现与锚点拖线一致的可见曲线，并实时跟随指针。
8. 悬停有效目标时目标节点与目标锚点高亮；无效目标不创建关系。
9. Canvas、HUD、关系交互聚焦测试、TypeScript 和 Windows 打包门禁通过。

## 验证计划

- 更新画布工作区布局、HUD contract、手势与关系交互测试。
- 新增持久化折叠状态的纯策略或 store source contract。
- 运行全部 `canvas-*.test.mjs`、`tsc --noEmit`、Windows Cargo 门禁和 NSIS 打包。
- 覆盖安装到 `F:\zeroxBApp`，保留现有数据库，实机验证折叠状态重启恢复与拖线预览。
