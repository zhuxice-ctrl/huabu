# zeroxB 画布优先与直接操控交互设计

## 目标

zeroxB 启动后直接进入无限画布，画布是产品的核心工作区。Markdown 笔记、记录列表和设置仍然保留，但降级为通过顶部入口打开的子功能，不再占据默认首屏。

本次设计同时统一画布的区块创建、内容拖放、样式调整和关系连线手势，并要求所有修改进入现有撤销与重做历史。

## 首屏与导航

- 启动时恢复最近一次打开的画布。
- 如果当前工作区没有画布，自动创建一张“未命名画布”并立即打开。
- 默认界面只保留画布、顶部全局入口、画布工具和底部 AI 对话坞。
- 笔记、记录、搜索和设置通过顶部入口打开，可显示为临时标签页或浮层；关闭后回到画布。
- 已打开的 Markdown 标签允许继续编辑，但不会替代画布作为下次启动的默认首屏。

## 鼠标与键盘交互

### 左键

- 在空白画布按下并拖动：显示实时矩形预览，松开后按矩形尺寸创建文本区块并立即进入编辑。
- 拖动距离小于 6px 时视为普通空白单击，只清除选择，不创建区块。
- 新区块最小尺寸为 120×72px；用户拖出的宽高大于最小值时完全保留。
- 在已有区块上拖动：移动区块。
- 单击区块：选中区块。
- 双击区块：编辑区块内容。

### 中键与滚轮

- 中键按下并拖动：平移无限画布。
- 滚轮：围绕指针位置缩放画布。
- 中键平移不改变当前工具，也不产生历史记录。

### 右键单击

- 区块上右键单击：打开区块菜单，包括编辑、复制、关联、背景色、字体色、字号、边框和删除。
- 空白画布右键单击：打开画布菜单，包括选择、画笔、荧光笔、橡皮擦、背景、网格和吸附设置。

### 右键长按关系连线

- 在区块上按住右键 320ms 后进入关系连线状态。
- 长按过程中拖动会从源区块引出预览线，并高亮可连接的目标区块。
- 松开到另一个区块时创建关系；松开到空白处、源区块自身或无效目标时取消，不写入数据。
- 320ms 内松开且移动距离不超过 6px 时仍执行普通右键菜单。
- 关系创建后在线条中点附近显示轻量编辑浮层，不创建额外文本区块。
- 编辑浮层包含关系名称、方向（单向或双向）、线型和颜色。Enter 保存，Esc 取消本次创建，点击外部保存当前有效值。

## 粘贴与拖放

画布统一解析 `paste` 和 `drop` 事件，并在指针或剪贴板焦点对应的画布坐标创建内容：

- 纯文本或富文本：去除危险标记后创建文本区块。
- URL：创建链接卡片。
- 图片：创建图片区块。
- 普通文件：创建文件区块。
- 多项内容：按固定间距级联排列，避免完全重叠。

粘贴文本使用内容测量结果确定尺寸：宽度限制为 240–520px，高度随内容增长，并遵守最小高度 72px。图片文字不在拖入时自动 OCR，避免阻塞交互；OCR 作为后续手动操作保留。

文件读取失败、无支持内容或解析为空时不创建节点，并使用非阻塞提示说明原因。

## 区块视觉与样式

文本区块数据增加并持久化以下样式字段：

- `backgroundColor`
- `textColor`
- `fontSize`
- `borderStyle`
- `borderColor`

右键菜单首先展示一组与深浅主题兼容的常用预设色；“自定义”入口打开完整取色器。字号提供小、标准、大、标题四档。边框提供无边框、细实线、虚线和强调边框。

样式修改立即预览，关闭菜单后保留。一次菜单会话中的连续颜色调整合并为一个撤销步骤，避免历史记录被每次取色变化淹没。

## 关系数据

关系继续使用画布边数据，不创建隐藏节点或文本节点。关系数据包含：

```ts
interface CanvasRelationData {
  label: string
  direction: 'forward' | 'both'
  lineStyle: 'solid' | 'dashed' | 'dotted'
  color: string
  source: 'manual' | 'ai'
}
```

手动关系和 AI 自动关系共用同一结构。AI 可以新增、编辑或删除 AI 关系，但不得移动用户手动摆放的区块。关系标签显示在线条附近，编辑浮层锚定到关系线中点并随视口缩放和平移更新位置。

## 组件边界

### CanvasStartupController

负责恢复最近画布、在空工作区创建默认画布，以及阻止 Markdown 标签成为下次启动的默认首屏。

### CanvasGestureController

负责指针按键判定、拖框预览、中键平移、右键单击与长按仲裁。控制器只输出明确意图，不直接写数据库。

### CanvasContentIngestor

负责解析剪贴板和拖放内容，将输入转换为标准节点草稿，并计算创建位置和初始尺寸。

### CanvasNodeStyleMenu

负责区块样式预设、取色器、字号和边框设置，并将一次菜单会话合并成单个历史命令。

### CanvasRelationController

负责关系预览线、目标吸附、关系写入和浮层定位。它通过现有画布存储和历史接口提交修改。

## 撤销、持久化与安全

以下操作各自形成一个原子历史步骤：

- 拖框创建区块
- 粘贴或拖放一批内容
- 移动区块
- 完成一次样式菜单编辑
- 创建关系
- 编辑关系
- 删除区块或关系

取消手势、无效拖放和未完成的关系不会进入历史。自动保存只保存已提交状态，不保存拖框预览、关系预览线或尚未确认的临时样式。

## 验证范围

- 冷启动、已有画布启动和空工作区启动均直接进入画布。
- Markdown 标签存在时重启仍恢复最近画布。
- 左键拖框、节点移动、中键平移和滚轮缩放互不冲突。
- 右键单击稳定打开菜单，右键长按稳定创建关系。
- 关系落到空白、自身或失效节点时不会残留数据。
- 文本、URL、图片和文件的粘贴与拖放结果正确，文本尺寸处于限定范围。
- 区块样式和关系样式重启后保持。
- 每种写操作均可一次撤销和重做。
- AI 创建的关系使用相同数据结构，且不会改变手动节点位置。

## 非目标

- 不在拖入图片时自动执行 OCR。
- 不新增导出功能。
- 不重写画布渲染引擎。
- 不把关系说明实现为独立文本节点。
- 不恢复多信息面板作为画布默认布局。
