# zeroxB 画布手势与可编辑关系线设计

日期：2026-07-24

## 目标

在不改变用户手动放置区块位置和内容的前提下，让 zeroxB 的画布交互更接近 React Flow 的直接操作体验：空白处右键拖动框选，区块上右键长按创建关系，关系线实时跟随光标并可在保存后继续编辑路径，同时修正空白点击误建大区块的问题。

## 已确认的交互规则

### 右键手势路由

- 在画布空白处按下右键并拖动时显示框选区域。
- 选择框与区块发生部分重叠即选中该区块，这是用户确认的选择规则。
- 框选完成后保留多选状态；右键菜单的删除命令和 `Delete`/`Backspace` 可一次删除所选区块及其关联线。
- 批量删除进入现有撤销历史，可通过撤销恢复。
- 在空白处只按下并松开右键、不形成拖动时，继续打开现有画布右键菜单。
- 在区块上只单击右键时，继续打开区块右键菜单。
- 在区块上按住右键达到长按阈值时进入关系拖动；这一路径不触发框选或文本块创建。
- 中键拖动画布的现有平移行为保持不变。

### 文本区块创建

- 左键单击空白处不创建区块，只清除选择或完成焦点切换。
- 只有横向和纵向都产生有效位移、形成二维面积时才创建文本区块。
- 仅沿单一轴向拖动形成的线不创建区块。
- 创建后的区块使用用户实际拖出的宽高，不再套用原有 `120 × 72` 的最小尺寸。
- 使用很小的指针抖动容差过滤误操作，但容差只决定是否创建，不会放大已经创建的区块。

### 关系创建与实时反馈

- 右键长按区块进入关系拖动后，立即渲染从源区块连接点到光标的平滑贝塞尔预览线。
- 预览线使用清晰的虚线或脉冲反馈，与参考图中的 React Flow 连接预览一致。
- 光标进入有效目标区块时，目标区块和目标连接点显示吸附高亮；离开后恢复。
- 松开到有效目标时创建关系并在线条附近打开关系编辑器。
- 松开到空白、源区块自身或无效目标时取消，不残留关系线或历史记录。

## 关系数据与路径模型

`CanvasRelationData` 在保持旧画布兼容的基础上增加可选字段：

- `routeType`: `auto`、`bezier`、`straight`、`orthogonal` 或 `manual`。
- `strokeWidth`: 关系线宽度。
- `waypoints`: 画布坐标系中的手动路径节点数组。
- 现有 `color`、`lineStyle`、`direction`、`label` 和 `source` 字段继续保留。

旧关系没有新字段时按以下默认值归一化：`routeType = auto`、`strokeWidth = 2`、`waypoints = []`。不要求数据库迁移，也不修改旧画布中的节点坐标。

## 自定义关系线

zeroxB 继续以 React Flow 作为画布与连接基础，但为关系边注册自定义 edge 组件。

- `auto`：默认模式。先生成自然的贝塞尔曲线；若路径明显穿过无关区块，则在区块外侧选择较短的绕行方向，并生成带圆角的绕行路径。
- `bezier`：固定平滑曲线，不自动插入折点。
- `straight`：端点之间的直线。
- `orthogonal`：水平和垂直线段组成的圆角折线。
- `manual`：依次经过用户保存的路径节点，节点之间使用圆角折线或平滑段连接。

自定义 edge 同时渲染一条不可见的较宽命中路径，保证细线也能可靠右键命中。显示路径本身遵循颜色、粗细、实线/虚线/点线和箭头设置。

## 二次编辑

- 右键单击关系线，将其设为当前关系并打开贴近点击位置的关系编辑器。
- 编辑器允许修改标签、方向、线型、颜色、粗细和路径类型。
- “增加路径节点”在当前关系的中段加入一个可拖动控制点；控制点显示在画布上，但不是文本区块，也不进入区块列表。
- 选中控制点后可拖动或删除；保存后再次打开同一关系仍能继续编辑。
- 切换为 `auto`、`bezier` 或 `straight` 时保留已有手动节点数据但暂不使用，避免来回切换时丢失用户路径。
- 所有保存操作在写入前建立一次历史快照；取消编辑恢复未保存状态，新建关系时取消则删除临时关系。

## 框选与关系手势冲突处理

手势由按下位置和按键唯一分流：

1. 空白处右键拖动只负责框选。
2. 区块上右键长按只负责关系创建。
3. 关系线上右键只负责关系编辑。
4. 右键短按且没有超过拖动阈值时保留现有菜单。

框选区域使用屏幕坐标显示，再通过 React Flow 的坐标转换计算与节点矩形的相交关系。选择结果按“部分相交”规则一次性写回，避免拖动期间反复抖动。

## 工具栏精简

删除参考截图中的四个快捷创建按钮：流程区块、判断区块、终止区块和文本区块。保留与当前产品方向相关的画布工具、笔记/图片导入和条件式编辑入口。文本区块的主要入口统一为画布拖动、粘贴和拖入内容。

## 代码边界

- `src/lib/canvas/gesture-policy.ts`：二维面积判定、框选矩形归一化、手势意图分类和矩形相交等纯函数。
- `src/lib/canvas/relation-policy.ts`：关系默认值、向后兼容归一化、视觉属性和路径模式策略。
- `src/lib/canvas/relation-routing.ts`：贝塞尔、折线、手动节点和简单避障路径计算。
- `src/app/core/main/canvas/canvas-edge.tsx`：自定义关系线、命中区域和路径控制点。
- `src/app/core/main/canvas/canvas-relation-editor.tsx`：关系属性和路径模式编辑。
- `src/app/core/main/canvas/canvas-editor.tsx`：指针会话编排、React Flow 配置、框选/关系预览覆盖层、历史与持久化集成。
- `src/types/canvas.ts`：持久化关系字段。

纯策略和路径计算从大型编辑器组件中拆出，便于独立测试；编辑器只负责事件编排和状态落盘。

## 异常与安全处理

- 指针取消、窗口失焦或捕获丢失时清除框选、关系预览和目标高亮。
- 无效目标不写入关系。
- 载入旧关系时对缺失或非法新字段使用安全默认值。
- 路径计算失败时回退到普通贝塞尔曲线，画布保持可用。
- 所有批量删除、关系属性修改和路径节点修改都进入现有撤销/重做栈。
- 不调用 AI、不移动现有区块，也不读取或输出本机模型密钥。

## 方案选择

采用“React Flow 基础能力 + zeroxB 自定义关系线”。只使用 React Flow 内置边无法提供持久化的手动路径节点；引入完整自动布线引擎则会显著增加包体、布局副作用和调试成本。当前方案能提供参考图所需的直接反馈和可编辑路径，同时保持现有画布架构与节点位置稳定。
