# 画布（Huabu）产品设计规格

- 日期：2026-07-24
- 状态：已确认，待实施计划
- 产品形态：Windows 本地优先桌面应用
- 开源许可证：GPL-3.0
- 技术母体：NoteGen `dev` 分支提交 `636d4f8`

## 1. 产品定义

画布是一款 AI 原生的空间笔记与个人记忆应用。用户在无限画布上自由放置文本、图片、笔记、PDF、网页链接、视频链接和通用附件；AI 在不打断写作的前提下完成检索、定位、标签、关系发现和受控编辑。

产品的核心不是让 AI 生成另一份整理结果，而是让 AI 理解用户已有内容，并把答案、关系和操作准确锚定到原始画布节点。

第一版只支持 Windows 10/11，不提供网页版、macOS、Linux 或移动端。

## 2. 核心原则

1. **画布优先**：无限画布是默认首页和主要工作环境，传统文件列表与聊天界面不得抢占主空间。
2. **本地优先**：原文、附件、索引、关系和操作历史默认保存在用户电脑中。
3. **证据优先**：关于用户历史的回答必须来自画布或本地附件，并提供可点击的原文依据。
4. **权限由代码控制**：AI 权限不能只依赖提示词，所有写操作必须经过权限网关。
5. **操作可回退**：每次 AI 编辑都是独立、可审计、可逆的事务。
6. **派生数据隔离**：AI 标签和 AI 关系与用户原文、手工布局及手工连线分开保存。
7. **渐进增强**：未配置模型、断网或索引故障时，基础写作、画布和全文搜索仍可使用。
8. **界面克制**：不使用常驻信息面板，AI 状态和结果按需从底部对话坞展开。

## 3. 开源与上游策略

画布作为独立品牌和独立产品路线发展，保留 NoteGen 原作者版权、许可证文本及 GPL-3.0 要求。

源码策略：

- 以 NoteGen 合入原生画布功能的提交 `636d4f8` 为技术起点。
- 将 NoteGen 官方仓库保留为 `upstream`，画布仓库作为 `origin`。
- 不追求长期与 NoteGen 保持同构，只选择性合并必要的安全修复和基础能力改进。
- 新功能优先落在边界清晰的模块中，减少与上游文件的冲突。
- 产品名称、包名、Windows 应用标识、图标和本地数据目录改为 Huabu。

保留的 NoteGen 基础能力：

- Tauri 2 Windows 桌面壳与文件权限。
- React、TypeScript、TipTap 和本地工作区。
- SQLite、全文搜索、Embedding、混合检索和模型配置。
- React Flow 画布、ELK 布局、撤销和历史机制。
- Agent 工具、操作预览和用户批准基础设施。

逐步替换的产品层：

- 以画布为中心的首页、导航和交互。
- 底部 AI 对话坞与状态动效。
- AI 权限模式、操作网关和事务系统。
- 记忆检索锚点、AI 标签、AI 关系及线性浏览。
- NoteGen 中与移动端、云同步及画布 MVP 无关的外围功能。

## 4. 系统边界

系统拆分为以下独立模块：

### 4.1 Canvas Core

负责节点、手工连线、位置、尺寸、分组、视口、选择和普通撤销。该模块不知道如何调用大模型。

### 4.2 Content Store

负责文本、附件、网页快照和媒体元数据。画布节点通过稳定内容 ID 引用内容，避免布局数据与正文耦合。

### 4.3 Knowledge Index

负责文本提取、OCR、分块、全文索引、Embedding、实体和时间信息。所有索引均可从原始内容重建。

### 4.4 AI Overlay

负责 AI 标签、AI 关系、置信度、关系理由和用户反馈。覆盖层可以显示、隐藏、重新生成或清空，不修改 Canvas Core。

### 4.5 AI Operation Gateway

负责检查当前权限模式、校验结构化操作、生成预览、申请确认、提交事务和回退。Agent 不得绕过网关直接写入画布状态。

### 4.6 Navigation

负责检索结果定位、镜头移动、节点高亮、返回查询前位置和关联内容线性浏览。

### 4.7 Recovery

负责事务日志、检查点、异常退出恢复、数据库迁移保护和备份轮换。

## 5. AI 权限模式

### 5.1 管理模式

应用启动时默认进入管理模式。允许 AI：

- 检索、回答和定位原文。
- 新增、更新或隐藏 AI 标签。
- 新增、更新或隐藏 AI 关系。
- 创建不改变原文的候选建议。

禁止 AI：

- 修改或删除用户原文。
- 移动、缩放或重排用户节点。
- 修改用户手工连线。
- 触发整张画布自动布局。

高置信度 AI 标签和 AI 关系可以自动应用，因为它们位于派生层且可随时撤销。中等置信度结果以候选样式显示，低置信度结果只参与检索。

### 5.2 编辑模式

编辑模式由用户显式开启，并按会话临时授权。应用重启、授权到期或发生安全异常后自动返回管理模式。

编辑模式允许 AI 提议：

- 新建、改写或删除节点。
- 移动、缩放、分组或调整节点布局。
- 新建、修改或删除用户关系。

所有操作先生成幽灵预览，不直接落库。删除、覆盖原文和大范围移动始终需要二次确认。

### 5.3 敏感内容

密码、密钥、身份证号等敏感节点具有独立安全标记。无论处于哪种模式，发送到云端模型前均由本地程序脱敏。AI 可以知道节点属于“凭据”类型，但默认不能读取真实值。

## 6. AI 操作事务

每次 AI 编辑作为一个不可拆分的事务保存：

- 事务 ID。
- 当前权限模式。
- 用户指令与 AI 操作说明。
- 使用的模型与时间。
- 受影响节点和关系。
- 操作前状态、操作后状态和反向操作。
- 预览、批准、应用、回退或失败状态。

普通操作保存正向和反向补丁。批量删除、大范围布局或数据库迁移前创建完整检查点。

执行流程：

```text
用户指令
→ AI 生成结构化操作计划
→ 权限网关校验
→ 幽灵预览与影响摘要
→ 用户确认（需要时）
→ 原子提交事务
→ 更新检索索引
→ 保存反向操作
```

AI 操作历史与普通手工撤销栈分开保存。用户既可撤销最近的普通编辑，也可将画布恢复到某次 AI 事务之前。

## 7. 数据结构

### 7.1 原始画布层

保存用户节点、手工连线、位置、尺寸、层级和分组。管理模式下，该层对 AI 只读。

### 7.2 AI 管理层

AI 标签至少保存：标签名称、规范化标签 ID、来源节点、置信度、理由、模型、时间和用户反馈。

AI 关系至少保存：起点、终点、关系类型、来源片段、判断理由、置信度、模型、时间和显示状态。

用户否定过的标签或关系进入抑制记录，后续分析不得重复创建等价结果。

### 7.3 检索锚点

每个知识片段保存：

- 工作区、画布和节点 ID。
- 原始文件或附件 ID。
- 文本起止范围。
- 节点坐标和内容更新时间。
- 全文索引字段和 Embedding。
- 实体、时间和内容类型。

锚点使回答可以定位到具体节点和原文范围，而不是只返回文件名。

## 8. 内容与节点类型

第一版支持：

- 文本和富文本节点。
- 本地笔记引用节点。
- 图片节点。
- PDF 节点。
- 网页链接和网页预览节点。
- 本地视频和视频链接节点。
- 通用附件节点。
- 待办节点。
- 分组节点。
- 自由绘制节点。

拖入内容时自动选择节点类型。粘贴网址时允许用户选择普通链接、网页预览或媒体嵌入。

本地视频可以在节点内播放。第一版不自动读取压缩包内全部文件，也不提供完整视频转录。文件包仅索引名称、目录和用户备注；视频仅索引标题、描述、已有字幕或用户备注。

## 9. 界面设计

界面参考 Stitch 的低干扰画布体验：画布占据完整窗口，控件悬浮在边缘，AI 对话位于底部中央。

### 9.1 主界面

- 左上角仅保留菜单、项目名和画布名。
- 右侧为悬浮画布工具条。
- 底部中央为 AI 对话坞。
- 左下角为默认折叠的 AI 状态/操作日志胶囊。
- 不使用常驻左侧筛选栏或右侧聊天面板。
- 标签、关系和时间筛选使用临时浮层，用完即收起。
- 同一时间最多出现一张主要信息卡。

产品不提供面向用户的导出功能，界面中不出现导出按钮或导出菜单。

### 9.2 AI 对话坞

底部对话坞承担：

- 普通问答和记忆检索。
- 语音输入。
- 图片和文件附件。
- 管理/编辑模式切换。
- AI 操作状态、预览和确认。

管理模式使用冷色和盾牌标识。编辑模式使用暖色边框、明确的“编辑”文字和授权倒计时。涉及修改时，发送按钮变为“预览操作”。

### 9.3 AI 呼吸状态

AI 状态以 Pulse、Morph 和 Blur 组合表达，动画服务于反馈而非装饰：

- 空闲：几乎静止的轻微呼吸。
- 聆听：随声音强弱柔和形变。
- 理解：蓝紫色慢速呼吸。
- 检索：光点向外扩散再汇聚。
- 定位：呼吸核心与目标节点同步亮起。
- 管理：青色脉冲，AI 关系逐渐显现。
- 编辑：橙紫色脉冲，幽灵节点同步呼吸。
- 等待确认：动画减慢并停留在暖色边框。
- 完成：一次短促扩张后回到空闲。
- 失败：轻微左右摆动，避免强烈闪烁。

动画优先使用 `transform`、`opacity` 和 GPU 合成层，并尊重 Windows 的减少动态效果设置。

### 9.4 AI 回答与定位

AI 回答在对话坞上方展开为轻量浮动卡，显示结论、日期和原文依据。点击依据后：

1. 回答卡收回底部。
2. 镜头平滑移动到目标节点。
3. 节点高亮具体命中原文。
4. 底部保留返回查询前位置和前后结果按钮。

多个候选使用底部横向结果条。低置信度检索不自动跳转，先让用户选择候选。

### 9.5 AI 编辑预览

- 新节点以半透明幽灵形态出现。
- 被移动节点显示原位置轮廓和移动轨迹。
- 文本修改只突出变化部分。
- 待删除节点降低透明度，不立即消失。
- 对话坞显示简短影响摘要。
- 用户可以应用全部、逐项检查、取消或退出编辑模式。

## 10. 分组与视图

分组采用保存的筛选视图，不复制节点内容。同一份数据可以按项目、主题、标签、人物或时间保存多个观察窗口。

系统提供同一数据的三种呈现：

- 画布：保留用户空间布局。
- 线性：阅读选中节点的关联内容。
- 关系：查看关系网络概览。

线性浏览可按时间、相关度、关系距离或用户手工顺序排列，并支持限制为一层或两层关系。进入线性视图不会改变画布位置，点击内容可返回原节点。

## 11. AI 索引与检索

节点新增或修改后，后台执行：

```text
内容提取/OCR
→ 分块
→ 实体与时间提取
→ 全文索引与 Embedding
→ 写入可恢复任务状态
```

文本与富文本直接提取；图片使用 OCR/VLM；PDF 和常见 Office 文档提取可读取文字；网页优先索引用户保存的正文快照；视频使用标题、描述、已有字幕和用户备注。任何提取失败都不得阻止原始内容保存。

检索组合：

1. 全文关键词。
2. 语义相似度。
3. 人物、地点、项目等实体。
4. 自然语言时间范围。
5. 可选重排序模型。

关于用户个人历史的事实只能由本地语料证实。模型自身知识可以帮助理解问题，但不得伪造用户过去写过的内容。没有可靠依据时必须回答“没有找到”。

## 12. 自动标签与关系

标签分为稳定标签和自由标签。稳定标签覆盖人物、地点、计划、账号、项目、灵感和待办等常见类别；自由标签根据用户内容逐渐形成。近义标签先给出合并建议，避免标签泛滥。

关系生成采用候选召回，而不是对所有节点两两调用模型：

```text
向量、实体和时间召回候选
→ 规则过滤
→ LLM 判断关系类型、理由和置信度
```

第一版关系类型：

- 同一主题。
- 补充说明。
- 时间延续。
- 计划与执行。
- 问题与解决。
- 人物或地点关联。
- 引用或来源。
- 可能重复。
- 凭据归属。

节点内容变化后，旧索引被标记为过期，相关 AI 标签和关系进入待复核状态。系统先降低旧关系显示强度，待新分析完成后更新；用户手工关系不受影响。

## 13. 模型与隐私

聊天、Embedding、重排序、OCR/VLM 分开配置，允许混用本地和云端模型。

- 本地模型第一版通过 Ollama 或 OpenAI 兼容本地接口使用。
- 云端模型通过用户配置的 OpenAI 兼容 API 使用。
- API 密钥写入 Windows Credential Manager，不写入画布数据库。
- 敏感内容在发送云端前由本地程序脱敏。
- 网页和附件内容视为不可信数据，不得被解释为 AI 操作指令。
- 无模型时保留全文搜索、手工标签和手工连线。

## 14. Windows 存储与恢复

默认建议工作区：

```text
文档\Huabu\
├─ workspace.db
├─ assets\
├─ notes\
├─ thumbnails\
└─ backups\
```

应用配置、日志和临时缓存存放在 `%LOCALAPPDATA%\Huabu\`。SQLite 启用 WAL 模式，附件使用内容哈希去重。缩略图和检索索引属于可重建数据。

虽然产品不提供导出功能，但保留内部恢复机制：

- AI 操作前事务检查点。
- 定时增量快照。
- 删除内容进入内部回收区。
- 异常退出后检查未完成事务。
- 数据库迁移前创建兼容性快照。
- 恢复失败时只读打开工作区。
- 自动轮换旧备份。

设置中只提供检查工作区、恢复历史状态和清理旧备份，不提供导出入口。

## 15. 错误处理

- 模型不可用时，画布和全文搜索继续工作。
- Embedding 失败时，任务进入后台重试队列。
- 附件损坏时，只影响对应节点。
- 磁盘空间不足时停止附件写入并提示用户。
- AI 事务中断时回滚到操作前状态。
- 自动关系失败时保留旧关系并标记待更新。
- 索引损坏时从原始内容重建。
- 编辑模式发生安全异常时立即退出并撤销未确认操作。

状态默认收进底部 AI 对话坞或左下角状态胶囊，不创建常驻错误面板。

## 16. 测试策略

### 16.1 单元测试

- 权限矩阵和操作网关。
- 结构化操作校验和反向补丁。
- 标签规范化、关系抑制和置信度策略。
- 文本分块、检索锚点和敏感内容脱敏。

### 16.2 集成测试

- AI 预览、批准、提交和回退完整链路。
- 管理模式拒绝原始层写入。
- 编辑模式批量修改的原子性。
- 数据库迁移、异常退出和恢复。
- API 失败、断网、索引重建和后台任务恢复。

### 16.3 端到端测试

- 创建和编辑各种节点。
- 询问历史内容并定位到正确节点与原文。
- 在管理/编辑模式间切换。
- 预览、应用和撤销 AI 操作。
- 进入关联阅读并返回原画布位置。
- 无网络、无模型和损坏附件场景。

### 16.4 性能与安全测试

- 大画布缩放、拖动、选择和定位流畅度。
- 大量索引片段下的检索响应。
- 提示词注入不能绕过权限网关。
- 敏感内容发送云端前完成脱敏。
- 用户否定过的关系不会反复出现。

## 17. 第一版 MVP

包含：

- Windows 10/11 本地桌面端。
- 单用户、单机、多个本地画布。
- 文本、图片、笔记、PDF、网页、本地视频、视频链接和通用附件节点。
- 节点移动、缩放、分组和手工连线。
- 底部 AI 对话坞与呼吸状态。
- 管理模式、编辑模式和临时授权。
- AI 操作预览、确认、事务和回退。
- 全文、语义、实体和时间检索。
- 原文证据、镜头定位和返回原视图。
- AI 标签、AI 关系、置信度和用户反馈。
- 关联内容线性浏览和保存的筛选视图。
- OpenAI 兼容 API 与 Ollama。
- 自动备份和异常恢复。

不包含：

- macOS、Linux、移动端和网页版。
- 多人协作、云同步和账号系统。
- 面向用户的导出功能。
- 插件市场。
- Neo4j、Chroma 等独立数据库。
- 自动联网研究。
- 压缩包内容深度解析。
- 完整视频转录。
- 应用内下载和管理大型本地模型。

## 18. 验收标准

MVP 达到以下条件才视为完成：

1. 用户可以在 Windows 上创建并长期保存富媒体画布。
2. AI 可以根据本地内容回答记忆问题，并定位到正确原文。
3. 管理模式下 AI 无法修改原文、用户布局或手工关系。
4. 编辑模式下所有 AI 修改先预览，应用后可整体回退。
5. AI 标签与关系不污染原始画布数据，并可单独隐藏或重建。
